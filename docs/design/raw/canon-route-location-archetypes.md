# Canon-route location archetypes — raw capture (2026-07-18)

A brainstorming/decision-support list, developer-supplied: the source material's story route, location by
location (as fan games commonly use it for linear level ladders). **Per moat #8 we never use the names or
the route** — what we mine is the ARCHETYPES: each stop is a proven island *shape* (setting + resident
faction + central tension + event hooks) that #10's world-gen can instantiate with original names, in any
order, anywhere the region tier fits. The list's ORDER is also evidence: it is a difficulty ladder, which
validates our regions-get-harder-outward structure (TIERS.md) done open-world instead of linear.

|---|---|

**How #10 consumes this:** each row becomes an island-archetype def family candidate ({setting, resident
org shape, central tension, 2-3 event hooks}); world-gen draws archetypes per region tier and skins them
with original names/characters (the niche-echo rule applied to geography). The route order maps roughly
onto our region ladder (Unbounty → Quarter Sea → Paradises → New World), confirming the difficulty
gradient without the linearity.
