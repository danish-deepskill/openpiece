# Sealubbers — reference capture

Capture of **[sealubbers.com](https://sealubbers.com)** (July 2026) — *Sealubbers*, a free-to-play
open-world pirate RPG by solo developer **Captain Rubin** (Plunder LLC), set in the ocean world of
**Krucia**. It is the closest genre neighbor to openpiece: one person building an open-world sea game
around exploration, crew building, ship combat, factions, and treasure hunting.

## Why it's here

Direct overlap with openpiece's problem space, from a dev roughly one lap ahead: crew members as
stat-bearing units with abilities (their crew dossier ≈ our squad/crew plans), ships following
mathematical function paths for natural AI movement, faction reputation driving world reaction, and a
"rebuilt the core because the original systems didn't scale" arc (Update 1) that mirrors the reasoning
behind our foundation-first canon.
