## Provenance & method

Produced by the `deep-research` workflow (run `wf_8a77fc0c-2e7`, 2026-07-02): 5 search angles → 30 search
results → 23 sources fetched with claim extraction (115 falsifiable claims with verbatim quotes) → top 25
claims adversarially verified by 75 independent voters (25/25 confirmed, 0 refuted) → synthesized. The
verification *budget* stopped at 25 claims — everything below that line is ✅ (fetched, not voted). Known
still-unresearched categories: OSRS/EVE economy design, the Gambetta/Gaffer server-authoritative netcode
chain, WFC procgen verification, sim-LOD talks.

When adding a volume to this library: keep the per-source format (what it teaches · credibility evidence ·
free status + legal basis · dates/staleness · ballpiece mapping · trust level), and prefer verbatim quotes
over paraphrase — the quotes are what an agent can re-verify.
